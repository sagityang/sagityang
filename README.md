# Yang Yang

Independent developer and open-source maintainer focused on AI-assisted development, developer automation, project analysis, and secure tooling.

I build small, practical tools that help people understand codebases, improve workflows, and handle local diagnostics without leaking sensitive data.

## Current Work

- [Single Project Analyzer](https://github.com/sagityang/single-project-analyzer) - evidence-backed workflow for analyzing one project and producing Markdown plus offline HTML reports.
- [UKey Detector](https://github.com/sagityang/ukey-detector) - privacy-first, read-only UKey certificate and USB topology inspection for Windows.

## Focus Areas

- AI-assisted software development
- Project analysis and documentation workflows
- Local-first developer tools
- Privacy-safe diagnostics and security-minded automation
- Maintainable scripts, skills, and agent workflows

## Working Principles

- Keep tools small, readable, and useful.
- Prefer evidence over hype.
- Treat logs, credentials, local paths, screenshots, and generated reports as sensitive until reviewed.
- Write documentation that helps the next maintainer continue without guesswork.

## Repository Notes

Most repositories here are early, practical tools extracted from real workflows. Public code is kept intentionally conservative: synthetic examples, clear boundaries, and privacy-first defaults.
